# Global CLAUDE.md

Platí pre všetky projekty na tomto počítači. Projektový CLAUDE.md má prednosť.

## Jazyk

- Komunikuj po slovensky
- Kód, commit messages, docs — v angličtine
- Technické termíny (file paths, API names, príkazy) ponechaj v origináli

## Pracovný štýl

- Pracuj autonómne — nepýtaj sa na potvrdenie pri každom kroku
- Zastav len pri deštruktívnych operáciách (zmazanie dát, force push na main, drop DB)
- Keď niečo nefunguje: skús max 2–3 alternatívy, potom reportuj čo si skúšal a kde si zasekol
- Preferujem jeden bundlovaný commit/PR, nie mnoho malých

## Štýl odpovedí

- Bez lichotenia, bez "skvelá otázka", bez "určite!"
- Krátko a konkrétne — ak je odpoveď jednoduchá, daj ju priamo
- Ak mám na výber viac prístupov, navrhni jeden s odôvodnením — nie zoznam bez odporúčania

## Skills (dostupné globálne)

- `/prompt` — použiť len pre komplexné viac-krokové úlohy alebo nejasnú architektúru
- `/prompt-research` — deep research s viacerými agentmi
- `/prompt-article-readme` — generovanie README z projektu
